## ⚡ Как работает автодоставка

```
Покупатель оплачивает лот на FunPay
           ↓
FunPay автоматически отправляет покупателю ссылку и инструкцию
           ↓
Покупатель приглашает бота на свой пустой Discord сервер
           ↓
Вводит команду !wizard
           ↓
Выбирает язык (🇷🇺 или 🇬🇧) и шаблон сервера
           ↓
✅ Весь сервер настраивается автоматически за несколько секунд!
```

> **Вам не нужно ничего делать вручную!** Покупатель получает готовый сервер без вашего участия.

## 🛠️ Инструкция по настройке лота

### Шаг 1 — Создайте лот

1. Зайдите на [funpay.com](https://funpay.com) → Ваш профиль → **«Мои лоты»**
2. Нажмите **«Добавить лот»**
3. Выберите категорию: `Discord → Серверы / Оформление`
4. Введите название, например:
   ```
   🎥 Готовый Discord сервер — YouTube / Twitch | Авто-установка ботом
   ```
5. Вставьте описание из файла `G-SERVER_FunPay_RU.docx` (нужный шаблон)
6. Укажите цену и сохраните

### Шаг 2 — Настройте автодоставку

1. Откройте настройки лота
2. Найдите раздел **«Автоматическая доставка»** и включите переключатель
3. Вставьте в поле текст из раздела [«Текст для автодоставки»](#-текст-для-автодоставки) выше

### Шаг 3 — Пример настройки лота

```
Название:        🎥 Готовый Discord сервер | YouTube / Twitch | Авто-бот
Категория:       Discord → Серверы
Цена:            от 99 ₽
Авто-доставка:   ВКЛЮЧЕНА ✅
```
