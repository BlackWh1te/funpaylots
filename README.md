> 🔥🎬 Discord сервер ютубера под ключ | Авто-бот | Каналы + Роли за секунды!

> 💎🎥 Discord сервер для YouTube канала | Авто-установка | Роли + Каналы готовы!
> ```
>
> ### 💡 Как составить уникальное название:
> - Добавьте **2-3 своих эмодзи** в начало или конец
> - Перефразируйте текст своими словами
> - Добавьте уточнение: "за 30 сек", "под ключ", "для новичков", "профи настройка"
> - Поменяйте порядок слов
>

## ⚡ Как работает автодоставка

```
Покупатель оплачивает лот на FunPay
           ↓
FunPay автоматически отправляет покупателю ссылку и инструкцию
           ↓
Покупатель приглашает бота на свой пустой Discord сервер
           ↓
Вводит команду !wizard
           ↓
Выбирает язык (🇷🇺 или 🇬🇧) и шаблон сервера
           ↓
✅ Весь сервер настраивается автоматически за несколько секунд!
```

> **Вам не нужно ничего делать вручную!** Покупатель получает готовый сервер без вашего участия.

## 🤖 О боте G-SERVER — модули и функции

> Это поможет вам уверенно отвечать покупателям на вопросы о боте.

### 🧙 Команда !wizard — главная функция

`!wizard` — это интерактивный мастер настройки сервера. Одна команда создаёт **всю структуру сервера** с нуля:
- Все категории и каналы
- Полную иерархию ролей с правами доступа
- Базовую автомодерацию
- Все дополнительные модули

Процесс занимает **5–30 секунд** в зависимости от размера шаблона.

> Частые вопросы от покупателей и готовые ответы на них.

<details>
<summary><b>❓ Бот безопасен? Он не навредит моему серверу?</b></summary>

```
Да, бот абсолютно безопасен. Он только создаёт структуру сервера (каналы, роли,
категории). Он не читает ваши сообщения и не собирает данные.
Подтверждение: бот работает на более чем 500 серверах.
```

</details>

<details>
<summary><b>❓ Зачем боту права Администратора?</b></summary>

```
Права Администратора нужны только для первоначальной настройки — создания каналов,
ролей и категорий. После установки вы можете понизить права бота до обычного
участника, если хотите.
```

</details>

<details>
<summary><b>❓ Бот удалит мои существующие каналы?</b></summary>

```
Бот НЕ удаляет существующие каналы автоматически. Рекомендуем запускать !wizard
на пустом сервере для наилучшего результата. Если на сервере уже есть каналы,
новые добавятся к существующим.
```

</details>

<details>
<summary><b>❓ Можно ли изменить каналы и роли после установки?</b></summary>

```
Да! После установки вы становитесь полноправным владельцем сервера. Вы можете
переименовывать, удалять и добавлять каналы и роли в любое время через
обычные настройки Discord.
```

</details>

<details>
<summary><b>❓ Что такое Premium? Это обязательно?</b></summary>

```
Premium — это расширенные функции бота (автомодерация, уровни, экономика,
розыгрыши и др.). Нет, это не обязательно! После установки вы получаете
30 дней Premium бесплатно. После окончания — базовые модули (тикеты,
верификация, welcome, reaction roles) остаются бесплатными навсегда.
```

</details>

<details>
<summary><b>❓ Бот перестанет работать если я не куплю Premium?</b></summary>

```
Нет! Основные модули работают бесплатно навсегда:
✅ Система тикетов
✅ Верификация
✅ Приветствие новых участников
✅ Reaction Roles (роли через реакции)
✅ Autorole
✅ Предложения

Premium функции (автомодерация, уровни, экономика и др.) потребуют подписки
после истечения пробного периода.
```

</details>

<details>
<summary><b>❓ Как запустить бота на сервере?</b></summary>

```
1. Добавьте бота по ссылке: 
https://discord.com/api/oauth2/authorize?client_id=1517454018547417148&permissions=8&integration_type=0&scope=bot+applications.commands
2. Введите команду !wizard на вашем сервере
3. Выберите язык и шаблон в интерактивном меню
4. Готово! Сервер настроится автоматически за несколько секунд.
```

</details>

<details>
<summary><b>❓ Могу ли я установить шаблон повторно или сменить его?</b></summary>

```
Да, вы можете запустить !wizard повторно для обновления структуры сервера.
Учтите, что новый шаблон добавит новые каналы и роли поверх существующих.
Для полной смены шаблона рекомендуем начать с пустого сервера.
```

</details>

<details>
<summary><b>❓ У меня ошибка при запуске !wizard — что делать?</b></summary>

```
Попробуйте следующее:
1. Убедитесь, что бот добавлен с правами Администратора
2. Попробуйте ещё раз через 1–2 минуты
3. Убедитесь, что вы — владелец сервера (команда доступна только владельцу)
4. Если ошибка повторяется — напишите в поддержку на сайте gserver.online
```

</details>

<details>

Да! Бот полностью поддерживает русский и английский языки.
При запуске !wizard вы выбираете язык интерфейса (🇷🇺 или 🇬🇧),
и весь сервер создаётся на выбранном языке.
```

</details>
