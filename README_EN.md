> ## ⚠️ IMPORTANT FOR SELLERS — READ BEFORE CREATING LOTS!
>
> The lot descriptions in this document are **templates**.
> Before publishing, **be sure to change the lot title**, adding your unique emojis and words.
>
> ### ❌ Bad — looks the same for all sellers:
> ```
> 🎥 READY DISCORD SERVER — YouTube / Twitch | Auto-installation by bot
> ```
>
> ### ✅ Good — unique title:
> ```
> ⚡🎥 READY Discord server for Streamers | YouTube Twitch | Auto-setup in 30 sec!
> 🔥🎬 Discord server for YouTubers | Auto-bot | Channels + Roles in seconds!
> 🚀🎥 Discord setup for streamers | YouTube / Twitch | Fully automated!
> 💎🎥 Discord server for YouTube channel | Auto-setup | Roles + Channels ready!
> ```
>
> ### 💡 How to create a unique title:
> - Add **2-3 of your own emojis** at the beginning or end
> - Rephrase the text in your own words
> - Add clarifications: "in 30 sec", "turnkey", "for beginners", "pro setup"
> - Change the word order
>
> **The lot description** (text below the title) is also recommended to be changed slightly — at least the first 1-2 lines.

## ⚡ How Auto-Delivery Works

```
The buyer pays for the lot on FunPay
           ↓
FunPay automatically sends the link and instructions to the buyer
           ↓
The buyer invites the bot to their empty Discord server
           ↓
Types the command !wizard
           ↓
Selects language (🇷🇺 or 🇬🇧) and server template
           ↓
✅ The entire server is set up automatically in a few seconds!
```

> **You don't need to do anything manually!** The buyer gets a ready server without your participation.

## 🤖 About G-SERVER Bot — Modules and Features

> This will help you confidently answer buyer questions about the bot.

### 🧙 The !wizard command — main feature

`!wizard` is an interactive server setup wizard. One command creates the **entire server structure** from scratch:
- All categories and channels
- Full role hierarchy with permissions
- Basic automoderation
- All additional modules

The process takes **5–30 seconds** depending on the template size.
