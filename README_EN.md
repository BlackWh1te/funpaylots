`!wizard` is an interactive server setup wizard. One command creates the **entire server structure** from scratch:
- All categories and channels
- Full role hierarchy with permissions
- Basic automoderation
- All additional modules

The process takes **5–30 seconds** depending on the template size.

## 🛠️ Instructions for Setting Up a Lot

### Step 1 — Create a lot
1. Go to [funpay.com](https://funpay.com) → Your profile → **"My lots"**
2. Click **"Add lot"**
3. Category: `Discord → Servers / Design`
4. Title: `🎥 Ready Discord server — YouTube / Twitch | Auto-installation by bot`
5. Description: copy from the ["Lot Descriptions"](#-lot-descriptions) section above
6. Set the price → Save

### Step 2 — Set up auto-delivery
1. Open the lot settings
2. Turn on **"Automatic delivery"**

## ❓ FAQ — Seller's Cheat Sheet

> Frequent questions from buyers and ready answers for them.

<details>
<summary><b>❓ Is the bot safe? Will it harm my server?</b></summary>

```
Yes, the bot is completely safe. It only creates the server structure (channels, roles,
categories). It does not read your messages and does not collect data.
Proof: the bot works on more than 500 servers.
```

</details>

<details>
<summary><b>❓ Why does the bot need Administrator permissions?</b></summary>

```
Administrator permissions are only needed for the initial setup — creating channels,
roles, and categories. After installation, you can downgrade the bot's permissions to a regular
member if you want.
```

</details>

<details>
<summary><b>❓ Will the bot delete my existing channels?</b></summary>

```
The bot DOES NOT automatically delete existing channels. We recommend running !wizard
on an empty server for the best results. If the server already has channels,
the new ones will be added alongside the existing ones.
```

</details>

<details>
<summary><b>❓ Can I change channels and roles after installation?</b></summary>

```
Yes! After installation, you become the full owner of the server. You can
rename, delete, and add channels and roles at any time through
regular Discord settings.
```

</details>

<details>
<summary><b>❓ What is Premium? Is it required?</b></summary>

```
Premium includes advanced bot features (automoderation, leveling, economy,
giveaways, etc.). No, it is not required! After installation, you get
30 days of Premium for free. After expiration — basic modules (tickets,
verification, welcome, reaction roles) remain free forever.
```

</details>
